SharePoint OS は、SharePoint Online の上にデスクトップ風の画面を重ねるユーザースクリプトです。SharePoint サイト（`https://*.sharepoint.com/*`）を開くと、デスクトップ、スタートメニュー、タスクバーが使えるようになり、毎日使うフォルダやファイルへのショートカットを置けます。

**できること**

- ショートカットをデスクトップに配置し、カテゴリ分けと色分け、お気に入り、最近使ったもの、更新バッジで整理する
- フォルダを動かせる窓で開き、ファイルをその場でプレビューする（テキストビューア内蔵）
- サイト全体を検索し、ZIPファイルをフォルダのように開く
- SharePoint REST APIによるファイル操作。アップロード（ドラッグ＆ドロップ対応）、移動、コピー、名前変更、削除、ダウンロード
- フォルダの容量表示、レイアウトと全設定のバックアップ／復元
- テーマプリセット252件からの切り替え、書体と文字サイズの変更
- 日本語／English の言語切替（初回はブラウザの言語で決定、テーマ窓の機能の切替で変更可）
- 使わない演出・3Dビュー・演出つきテーマは初期設定でオフ（ライトモード。テーマ窓の「🧩 機能の切替」でオンにできます）
- 独立モジュール。3Dビュー、ショートカット健全性チェック（リンク切れ・権限なし・重複の確認）、スマホ・タブレット向けタッチモード、長押し＝右クリック、離席中に更新されたものを知らせる「おかえり」のお知らせ
- 操作ログ（このブラウザにだけ最大500件）。このUIで行った名前変更・移動・コピー・削除は、ログから元に戻せる

**必要なもの**

- Tampermonkey などのユーザースクリプトマネージャ
- SharePoint Online サイトへのアクセス権。動作はすべて利用者自身の SharePoint 権限の範囲内で、アカウントが見られないもの・変えられないものを扱うことはありません

**プライバシー**

設定、レイアウト、操作ログの保存先は、このブラウザの localStorage です。通信先は利用者自身の SharePoint テナント（同じテナントの個人用 OneDrive を含む）で、作者や第三者のサーバーへデータは送りません。

**注意**

- 本体とデータファイル2本（Greasy Fork のライブラリとして別掲載）を @require で読み込む構成です（合計 約2.2 MB）。
- メニュー項目「最新の日付シートを確認」は、Excel ブック（xlsx / xlsm）で使えます。初期設定では全ブックが対象で、名前に含む語で絞ることもできます（テーマ窓の機能の切替で設定）。
